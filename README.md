# Лабораторная работа 3. Технология MapReduce

Вариант 11: **DevOps-инженер**. Репозиторий содержит воспроизводимый пайплайн анализа вакансий 2024 года: RustFS (S3), собственный MapReduce с чтением Range-чанками, независимый SQL-расчёт DuckDB, автоматическую сверку, профилирование и анализ зарплат/регионов.

## Быстрый запуск

```bash
cp .env.example .env
make setup
make up
make prepare CSV=/absolute/path/to/it_vacancies_2024.csv
make upload
make profile
make analyze
.venv/bin/python -m src.storage upload-results
```

Консоль RustFS: <http://localhost:9001>. S3 API: <http://localhost:9000>. Бакет: `hh-lake`.
Четыре диска реализованы отдельными именованными Docker-томами и подключены как `/data1` ... `/data4`. Размеры: `docker exec lab3-rustfs du -sh /data{1,2,3,4}`.

## Условие варианта

Используется точный фильтр `role = 'DevOps-инженер'`. Это поле классификатора HH. Поиск `DevOps` в названии не применяется, поскольку он примешивает вакансии с другими ролями.

## Архитектура

1. `src.prepare` потоково читает исходный CSV и создаёт NDJSON сегмента варианта.
2. `src.storage` загружает объект в `s3://hh-lake/variants/11-devops/vacancies.ndjson`.
3. `src.mapreduce_job` получает размер объекта, делит байтовый диапазон на чанки, параллельно выполняет Range GET и сворачивает частоты навыков, пар и троек.
4. `src.duckdb_job` независимо читает тот же S3-объект расширением `httpfs` и считает контрольные таблицы SQL-запросами.
5. `src.verify` требует полного совпадения частот и медиан.
6. `src.profile_runs` выполняет каждый способ минимум три раза и измеряет wall time и пиковый RSS всего дерева процессов.
7. `src.analysis` строит региональные таблицы и сравнивает медиану комбинации с наиболее частым подмножеством на один навык короче.

## Артефакты

Результаты создаются в `artifacts/results/`, журналы запусков — в `artifacts/run-logs/`. PDF-отчёт находится в `report/`.

## Важные определения

- Навыки очищаются, дедуплицируются без учёта регистра внутри вакансии и сортируются перед построением сочетаний.
- Зарплата учитывается только в RUR. Для интервала берётся середина, для одной границы — указанная граница. Зарплата `gross=false` переводится в gross делением на `0.87`.
- Вакансии без зарплаты участвуют в частотах, но не в медианах.
- Пара/тройка внутри одной вакансии считается один раз.
